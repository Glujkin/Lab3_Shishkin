В ходе выполнения первого шага лабораторной работы был инициализирован локальный Git-репозиторий и создан файл `README.md`. 

Для синхронизации с GitHub были выполнены следующие команды:
1. `git remote add origin <URL>` — привязка локального репозитория к удаленному.
2. `git push -u origin master` — отправка начального коммита на сервер.

В результате на GitHub была создана ветка `master`, а локальная ветка настроена на отслеживание удаленной.
